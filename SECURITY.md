# Security

tokenpanda reads files on your Mac and edits one key in `~/.claude/settings.json` when you click to install its status line hook. If you find a way it reads, writes or exposes more than the [privacy page](docs/privacy.html) says, I want to know.

Report it through the private security advisory form of the repository: Security, then Report a vulnerability, on github.com/tokenpandadev/tokenpanda-app. For anything that is not sensitive, a GitHub issue is fine.

Please include the version, your macOS version and the steps to see it. I will answer in the advisory and credit you in the changelog if you want that.

Our latest audit, run with AI agents against OWASP ASVS 5.0.0 Level 2 and not an outside audit, is at [tokenpanda.dev/audit](https://tokenpanda.dev/audit) with every open finding.
